# Fate Five Dungeon

카드 드로우로 스킬을 얻고, **합(Clash)** 으로 적을 쓰러뜨리며 층을 오르는 다크 판타지 로그라이크입니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

- GitHub Pages로 공개하려면 저장소 **Settings → Pages**에서 이 브랜치의 루트(`/`)를 선택하세요.
- 로컬 서버가 필요하면 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속하세요.

## 게임 규칙

### 시작 — 빛의 선택
순례를 시작할 때 **빛 15**가 주어집니다. 이 수치 안에서 가호(패시브)를 고릅니다. 가호의 비용은 효과가 강할수록 높아지며 1~4입니다.

### 전투 순서
1. 플레이어와 적 모두 **9장짜리 덱**에서 스킬 카드를 뽑습니다. 적이 이번 턴에 쓸 스킬은 미리 공개됩니다.
2. 턴당 **코스트 9**(기본값) 안에서 스킬 카드를 슬롯에 배치합니다. 스킬 코스트는 0~5이고, 강한 스킬일수록 코스트가 높습니다.
3. **전투 시작**을 누르면 같은 줄의 스킬끼리 합을 진행합니다.
4. 어느 한쪽 체력이 0이 될 때까지 이 과정을 반복합니다.

### 합 (림버스 컴퍼니 방식)
- **합 위력 = 기본 위력 + (앞면 코인 수 × 코인 위력)**. 코인 앞면 확률은 기본 50%입니다.
- 위력이 낮은 쪽은 코인 1개가 파괴됩니다. 비기면 다시 던집니다.
- 한쪽 스킬의 코인이 **모두 파괴될 때까지** 합을 반복합니다.
- 이긴 쪽은 **남은 코인으로 일방 공격**합니다. 코인을 하나씩 던지며 앞면마다 위력이 누적되고, 코인마다 그 위력만큼 피해를 줍니다.
- 상대 스킬이 없는 줄은 곧바로 일방 공격합니다.
- 줄마다 예상 합 승률이 **우세 / 균형 / 열세**로 표시됩니다.

### 공격 유형과 내성
스킬은 ⚔ 참격 / ➶ 관통 / ⚒ 타격 중 하나입니다. 적마다 내성이 달라 피해에 배율이 붙습니다.

| 내성 | 치명 | 약점 | 보통 | 인내 |
|---|---|---|---|---|
| 피해 배율 | ×2 | ×1.5 | ×1 | ×0.5 |

### 상태이상
| 상태 | 효과 |
|---|---|
| 🩸 출혈 | 공격 코인을 사용할 때마다 위력만큼 피해, 횟수 -1 |
| 🔥 화상 | 턴 종료 시 위력만큼 피해, 횟수 -1 |
| 💥 파열 | 피격 시 위력만큼 추가 피해, 횟수 -1 |
| 🌬️ 호흡 | 공격 적중 시 위력×5% 확률로 치명타(피해 +20%), 치명타 시 횟수 -1 |
| ⚡ 마비 | 다음 턴 코인 n개의 위력이 0으로 고정 |
| 🔻 위력 감소 / 🔺 위력 증가 | 다음 턴 모든 스킬의 기본 위력 ±n |
| 🔓 취약 | 다음 턴 받는 피해 +10% × n |

### 층과 지역
- 전투에서 이길 때마다 **랜덤 아이템 3개 중 1개**를 고릅니다. 아이템은 유물, 회복, 새 스킬 카드, 카드 강화 중 하나입니다.
- **3층**에 중간 보스가 나오고, 이후 **+5층마다**(8, 13, 18 …) 다시 나옵니다.
- **5층마다**(5, 10, 15 …) 지역 보스가 나옵니다. 보스를 쓰러뜨리면 **다음 지역을 선택**합니다.
- 지역은 5곳입니다: 잿빛 묘지, 썩은 숲, 피의 성당, 심연의 동굴, 서리 왕좌. 지역마다 어울리는 몬스터와 내성이 있습니다.
- 중간 보스와 보스는 **전용 카드 3장**과 **강력한 고유 스킬 1개**를 가집니다. 고유 스킬은 3턴마다 추가 슬롯으로 사용됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 진입점 |
| `css/style.css` | 다크 판타지 UI 스타일 (모바일 대응) |
| `js/data.js` | 카드, 빛(패시브), 아이템, 지역·몬스터, 밸런스 조정값 |
| `js/engine.js` | 화면과 분리된 전투·진행 규칙 |
| `js/game.js` | 화면 렌더링, 전투 연출, 입력 처리 |
| `tools/simulate.js` | 밸런스 확인용 자동 플레이 시뮬레이터 |

## 밸런스 조정

난이도는 `js/data.js`의 `BALANCE`에서 조정합니다. 플레이어 체력, 층당 적 체력과 위력 증가량, 보스 처치 후 회복량 등이 들어 있습니다. 값을 바꾼 뒤 시뮬레이터로 층별 돌파율을 확인할 수 있습니다.

```bash
node tools/simulate.js 1000
```
