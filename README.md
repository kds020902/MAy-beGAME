# Fate Five Dungeon

카드 드로우로 스킬을 얻고, **운명 주사위** 합으로 적을 쓰러뜨리며 층을 오르는 다크 판타지 로그라이크입니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

- GitHub Pages로 공개하려면 저장소 **Settings → Pages**에서 이 브랜치의 루트(`/`)를 선택하세요.
- 로컬 서버가 필요하면 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속하세요.

## 게임 규칙

### 시작 — 직업과 빛
1. **직업**을 고릅니다.

   | 직업 | 무기 | 체력 | 특성 | 성향 |
   |---|---|---|---|---|
   | 🗡️ 방랑검사 | 검 | 130 | 검의 길: 참격 주사위 위력 +2 | 참격과 회피만 쓰는 딜러 |
   | 🕊️ 전령 | 창과 성령 | 125 | 성령의 숨결: 매 턴 체력 1 회복 | 관통 공격과 회복·기도 |
   | 🛡️ 중기병 | 메이스와 갑옷 | 180 | 튼튼한 갑옷: 받는 피해 -2 | 타격과 방어로 버티는 탱커 |

2. **빛 9**로 가호(패시브)를 고릅니다. 가호의 비용은 효과가 강할수록 높아지며 1~4입니다.

### 전투 순서
1. 플레이어와 적 모두 **9장짜리 덱**에서 카드를 뽑습니다. 적이 이번 턴에 쓸 카드는 미리 공개됩니다.
2. 턴당 **코스트 9** 안에서 카드를 슬롯에 배치합니다. 카드 코스트는 0~5이고, 강한 카드일수록 코스트가 높습니다.
3. **전투 시작**을 누르면 전투 시작 효과(회복, 힘, 보호 등)가 먼저 적용되고, 같은 줄의 카드끼리 합을 진행합니다.
4. 어느 한쪽 체력이 0이 될 때까지 반복합니다.

### 운명 주사위 합
카드마다 주사위가 1~5개 있습니다. 두 카드의 주사위를 앞에서부터 하나씩 굴려 맞붙입니다.

| 맞붙은 주사위 | 결과 |
|---|---|
| 공격 vs 공격 | 높은 쪽이 굴린 값만큼 피해 |
| 공격 vs ⛨ 방어 | 공격이 높으면 차이만큼 피해, 방어가 높으면 차이만큼 반격 |
| 공격 vs ↯ 회피 | 회피가 높으면 공격을 피하고 회피 주사위를 다시 사용, 공격이 높으면 전부 피해 |
| 방어 vs 방어 | 아무 일도 없음 |

- 공격 주사위는 ⚔ 참격 / ➶ 관통 / ⚒ 타격 세 종류입니다. 적마다 내성이 달라 피해에 배율이 붙습니다: 치명 ×2, 약점 ×1.5, 보통 ×1, 인내 ×0.5.
- 한쪽 주사위가 먼저 떨어지면 남은 공격 주사위는 그대로 일방 공격합니다. 적 카드를 막지 않은 줄도 일방 공격을 받습니다.
- 줄마다 예상 피해(가함 / 받음)와 **우세 / 균형 / 열세**가 표시됩니다. **자동 배치**는 이 예상치가 가장 좋은 배치를 골라 줍니다.

### 상태이상
| 상태 | 효과 |
|---|---|
| 🩸 출혈 | 공격 주사위를 굴릴 때마다 수치만큼 피해, 수치 1/3 감소 |
| 🔥 화상 | 턴 종료 시 수치만큼 피해, 수치 절반 |
| 🔺 힘 / 🔻 허약 | 이번 턴 공격 주사위 위력 ±n |
| ⛨ 인내 | 이번 턴 방어·회피 주사위 위력 +n |
| 🛡 보호 / 🔓 취약 | 이번 턴 받는 피해 ∓n (적중마다) |

### 층, 지역, 상점
- 전투에서 이길 때마다 **은화**를 얻고, 랜덤 아이템 3개 중 1개를 고릅니다.
- **3층**에 중간 보스가 나오고, 이후 **+5층마다**(8, 13, 18 …) 다시 나옵니다.
- **5층마다**(5, 10, 15 …) 지역 보스가 나옵니다. 보스를 쓰러뜨리면 **상점**이 열리고, 이어서 **다음 지역을 선택**합니다.
- **상점**: 위쪽에 최하급 기본 물품 3개가 늘 있고(여러 번 구매 가능), 아래쪽에 일반~전설 물건 5개가 무작위로 나옵니다. 층이 높을수록 높은 등급이 나올 확률이 올라갑니다.
- 지역은 5곳입니다: 잿빛 묘지, 썩은 숲, 피의 성당, 심연의 동굴, 서리 왕좌. 지역마다 어울리는 몬스터와 내성이 있습니다.
- 중간 보스와 보스는 **전용 카드 3장**과 **강력한 고유 스킬 1개**를 가집니다. 고유 스킬은 3턴마다 추가 슬롯으로 사용됩니다.

## 이미지 만들기 (Codex)

직업·몬스터·아이템 이미지는 노트북의 [Codex CLI](https://github.com/openai/codex)로 만듭니다. 이미지가 없으면 게임은 아이콘으로 표시합니다.

```bash
npm install -g @openai/codex          # Codex CLI가 없다면
node tools/generate-images.js --list  # 만들 이미지와 프롬프트 확인 (54개)
node tools/generate-images.js         # 없는 이미지를 모두 생성
node tools/generate-images.js --only monsters   # 종류별로 나눠서 생성
```

- 이미지는 `assets/classes/`, `assets/monsters/`, `assets/items/`에 `<id>.png`로 저장됩니다.
- 생성이 끝나면 `assets/manifest.js`가 자동으로 갱신되고, 게임이 그 이미지를 사용합니다.
- 기본으로 `codex exec --full-auto "<지시문>"`을 실행합니다. Codex 버전에 따라 이미지 생성 방식이나 옵션이 다르면 `--codex "exec ..."`로 인자를 바꿀 수 있습니다. 지시문은 Codex 자체의 이미지 생성 기능을 쓰고, 없으면 `OPENAI_API_KEY`로 OpenAI 이미지 API를 호출하도록 안내합니다.
- 이미지를 직접 넣었다면 `node tools/generate-images.js --manifest`로 목록만 갱신하세요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 진입점 |
| `css/style.css` | 다크 판타지 UI 스타일 (모바일 대응) |
| `js/data.js` | 직업, 카드, 빛(패시브), 아이템, 상점, 지역·몬스터, 밸런스 조정값 |
| `js/engine.js` | 화면과 분리된 전투·진행 규칙 |
| `js/game.js` | 화면 렌더링, 전투 연출, 입력 처리 |
| `assets/manifest.js` | 게임이 사용할 이미지 목록 |
| `tools/simulate.js` | 밸런스 확인용 자동 플레이 시뮬레이터 |
| `tools/generate-images.js` | Codex로 이미지를 만드는 스크립트 |

## 밸런스 조정

난이도는 `js/data.js`의 `BALANCE`, 직업 수치는 `CLASSES`, 상점 가격과 등급 확률은 `SHOP`에서 조정합니다. 값을 바꾼 뒤 시뮬레이터로 직업별 층 돌파율을 확인할 수 있습니다.

```bash
node tools/simulate.js 300
```
