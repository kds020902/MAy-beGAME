# 오푸스덜스

카드 드로우로 스킬을 얻고, **운명 주사위** 합으로 적을 쓰러뜨리며 층을 오르는 다크 판타지 로그라이크입니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

- GitHub Pages로 공개하려면 저장소 **Settings → Pages**에서 이 브랜치의 루트(`/`)를 선택하세요.
- 로컬 서버가 필요하면 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속하세요.

## 게임 규칙

### 시작 — 직업과 빛
1. **직업**을 고릅니다.

   | 직업 | 무기 | 체력 | 코스트 | 턴당 스킬 | 특성 | 성향 |
   |---|---|---|---|---|---|---|
   | 🗡️ 방랑검사 | 검 | 110 | 13 | 3 | 검의 길 | 참격·회피, 출혈과 취약으로 몰아치는 딜러 |
   | 🕊️ 전령 | 창과 성령 | 130 | 9 | 2 | 성령의 숨결: 매 턴 체력 2 회복 | 관통 공격과 회복·기도 |
   | 🛡️ 중기병 | 메이스와 갑옷 | 220 | 8 | 2 | 튼튼한 갑옷: 받는 피해 -2 | 타격과 방어로 버티는 탱커 |

2. **빛 9**로 가호(패시브)를 고릅니다. 가호의 비용은 효과가 강할수록 높아지며 1~4입니다.

### 전투 순서
1. 플레이어와 적 모두 **9장짜리 덱**에서 카드 5장을 뽑습니다. 적이 이번 턴에 낼 카드는 몬스터 머리 위의 **의도**와 합 대진에 미리 공개됩니다.
2. 턴당 **코스트**(직업마다 8~13) 안에서, 직업별 **스킬 수**(2~3장)만큼 손패의 카드를 냅니다. 낸 카드는 합 대진의 빈 줄로 들어가고, 다시 누르면 손패로 돌아옵니다. 카드 코스트는 0~5이고, 강한 카드일수록 코스트가 높습니다.
3. **턴 종료**를 누르면 전투 시작 효과(회복, 힘, 보호 등)가 먼저 적용되고, 같은 줄의 카드끼리 합을 진행합니다.
4. 턴이 끝나면 **남은 손패는 모두 버린 카드 더미**로 가고, 다음 턴에 새로 5장을 뽑습니다. 뽑을 카드가 없으면 버린 카드를 섞어 다시 뽑습니다.
5. 어느 한쪽 체력이 0이 될 때까지 반복합니다.

화면은 위쪽에 체력·은화·층 정보와 유물, 가운데에 플레이어와 몬스터가 마주 선 전투 무대와 합 대진, 아래쪽에 에너지(코스트) 구슬·부채꼴 손패·턴 종료 버튼과 뽑을 카드/버린 카드 더미가 있습니다.

### 운명 주사위 합
카드마다 주사위가 1~5개 있습니다.

1. 양쪽 카드의 맨 앞 주사위를 굴려 **높은 쪽이 합에서 이깁니다.** 비기면 둘 다 다시 굴립니다.
2. **진 주사위만 파괴**됩니다. 이긴 주사위는 남아서 상대의 다음 주사위와 다시 굴려 합을 합니다.
3. 합이 끝나기 전에는 피해가 없습니다. 한쪽 주사위가 모두 파괴되면 합이 끝나고, **남은 쪽이 남은 공격 주사위를 다시 굴려 그 값만큼 공격**합니다.
4. 상대 카드가 없는 줄은 곧바로 모든 공격 주사위로 공격합니다. 적 카드를 막지 않은 줄은 그대로 맞습니다.

- 공격 주사위(⚔ 참격 / ➶ 관통 / ⚒ 타격)만 피해를 줍니다. 적마다 내성이 달라 피해에 배율이 붙습니다: 치명 ×2, 약점 ×1.5, 보통 ×1, 인내 ×0.5.
- ⛨ 방어 / ↯ 회피 주사위는 범위가 높아 합에서 상대 주사위를 부수는 데 쓰고, 피해는 주지 않습니다. 회피는 합에서 비기면 이깁니다.
- 줄마다 예상 피해(가함 / 받음)와 **우세 / 균형 / 열세**가 표시됩니다. **자동 배치**는 이 예상치가 가장 좋은 배치를 골라 줍니다.

### 전투 연출
- 가운데 무대에는 캐릭터만 서 있고, 발밑에 붉은 체력바와 노란 숫자의 코스트 구슬이 있습니다. 합 대진과 적 정보는 무대 아래 대진판에 있습니다.
- 합을 할 때 두 캐릭터가 주사위 종류에 맞는 자세로 달려가 부딪히고, 이긴 쪽이 진 쪽을 쳐내 밀어냅니다. 두 주사위 값의 차이가 클수록 멀리 밀려납니다.
- 스킬 이펙트는 VFX로 그립니다: 참격은 칼날 궤적, 관통은 찌르는 섬광, 타격은 충격파, 방어는 방패 빛, 회피는 잔상, 출혈·화상·회복은 입자.

### 상태이상
| 상태 | 효과 |
|---|---|
| 🩸 출혈 | 공격 주사위로 공격할 때마다 수치만큼 피해, 수치 1/3 감소 |
| 🔥 화상 | 턴 종료 시 수치만큼 피해, 수치 절반 |
| 🔺 힘 / 🔻 허약 | 이번 턴 공격 주사위 위력 ±n |
| ⛨ 인내 | 이번 턴 방어·회피 주사위 위력 +n |
| 🛡 보호 / 🔓 취약 | 이번 턴 받는 피해 ∓n (적중마다) |

### 층, 지역, 상점
- 전투에서 이길 때마다 **은화**를 얻고, 랜덤 아이템 3개 중 1개를 고릅니다.
- **3층**에 중간 보스가 나오고, 이후 **+5층마다**(8, 13, 18 …) 다시 나옵니다.
- **5층마다**(5, 10, 15 …) 지역 보스가 나옵니다. 보스를 쓰러뜨리면 **상점**이 열리고, 이어서 **다음 지역을 선택**합니다.
- **상점**: 위쪽에 최하급 기본 물품 3개가 늘 있고(여러 번 구매 가능), 아래쪽에 일반~전설 물건 5개가 무작위로 나옵니다. 층이 높을수록 높은 등급이 나올 확률이 올라갑니다.
- 지역은 5곳입니다: 잿빛 묘지, 썩은 숲, 피의 성당, 심연의 동굴, 서리 왕좌. 지역마다 어울리는 몬스터와 내성이 있습니다.
- 중간 보스와 보스는 **전용 카드 3장**과 **강력한 고유 스킬 1개**를 가집니다. 고유 스킬은 3턴마다 추가 슬롯으로 사용됩니다.

## 이미지 만들기 (Codex)

직업·몬스터·아이템 이미지 54개를 넣을 수 있습니다. 이미지가 없으면 게임은 아이콘으로 표시합니다.

**직접 만들 때**: [`IMAGE_PROMPTS.md`](IMAGE_PROMPTS.md)에 항목별 프롬프트와 저장 경로가 있습니다. 원하는 이미지 생성기로 만들어 그 경로에 저장한 뒤 아래를 실행하세요.

```bash
node tools/generate-images.js --manifest   # 이미지 목록 갱신
git add assets && git commit -m "이미지 추가" && git push
```

**Codex CLI로 한 번에 만들 때** (노트북에서):

```bash
npm install -g @openai/codex          # Codex CLI가 없다면
node tools/generate-images.js --list  # 만들 이미지와 프롬프트 확인 (54개)
node tools/generate-images.js         # 없는 이미지를 모두 생성
node tools/generate-images.js --only monsters   # 종류별로 나눠서 생성
```

- 이미지는 `assets/classes/`, `assets/monsters/`, `assets/items/`에 `<id>.png`로 저장됩니다.
- 생성이 끝나면 `assets/manifest.js`가 자동으로 갱신되고, 게임이 그 이미지를 사용합니다.
- 기본으로 `codex exec --full-auto "<지시문>"`을 실행합니다. Codex 버전에 따라 이미지 생성 방식이나 옵션이 다르면 `--codex "exec ..."`로 인자를 바꿀 수 있습니다. 지시문은 Codex 자체의 이미지 생성 기능을 쓰고, 없으면 `OPENAI_API_KEY`로 OpenAI 이미지 API를 호출하도록 안내합니다.
- 이미지를 직접 넣었다면 `node tools/generate-images.js --manifest`로 목록만 갱신하세요.

### 전투 자세 그림 (픽셀 아트)

전투 화면 가운데 무대에서 플레이어(왼쪽)와 적(오른쪽)이 행동마다 자세를 바꿉니다. 캐릭터마다 4장입니다.

| 자세 | 파일 | 나오는 때 |
|---|---|---|
| 대기 | `idle.png` | 평소 |
| 공격 | `attack.png` | 공격 주사위로 합에서 이겼을 때, 공격할 때 |
| 방어·회피 | `defend.png` | 방어·회피 주사위로 합에서 이겼을 때 |
| 피격 | `hit.png` | 피해를 받을 때 |

```bash
node tools/generate-sprites.js              # 없는 자세 그림을 모두 생성 (직업 3 + 몬스터 25 = 112장)
node tools/generate-sprites.js ghoul        # 특정 캐릭터만
node tools/generate-sprites.js --force ghoul   # 다시 만들기
node tools/generate-sprites.js --force --pose=attack   # 모든 캐릭터의 공격 자세만 다시 만들기
```

- 그림에는 이펙트(휘두르는 궤적, 섬광, 불꽃, 피 튀김 등)를 넣지 않습니다. 이펙트는 게임이 스킬을 쓸 때 VFX로 따로 그립니다. 예전에 만든 그림에 궤적이 들어가 있으면 위의 `--pose=attack` 명령으로 다시 만드세요.

- `assets/sprites/<id>/<자세>.png`로 저장되고, 끝나면 manifest가 갱신됩니다.
- 대기 그림을 먼저 만들고, 그 그림을 참고 이미지로 넣어 나머지 자세를 만들기 때문에 같은 캐릭터로 유지됩니다.
- 자세 그림이 없으면 대기 그림, 대기 그림도 없으면 아이콘으로 표시합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 진입점 |
| `css/style.css` | 다크 판타지 UI 스타일 (모바일 대응) |
| `js/data.js` | 직업, 카드, 빛(패시브), 아이템, 상점, 지역·몬스터, 밸런스 조정값 |
| `js/engine.js` | 화면과 분리된 전투·진행 규칙 |
| `js/game.js` | 화면 렌더링, 전투 연출, 입력 처리 |
| `assets/manifest.js` | 게임이 사용할 이미지 목록 |
| `tools/simulate.js` | 밸런스 확인용 자동 플레이 시뮬레이터 |
| `tools/generate-images.js` | Codex로 이미지를 만드는 스크립트 |
| `tools/image-prompts.js` | 이미지 프롬프트 (`IMAGE_PROMPTS.md`의 원본) |
| `tools/generate-sprites.js` | Codex로 전투 자세 그림을 만드는 스크립트 |

## 밸런스 조정

난이도는 `js/data.js`의 `BALANCE`, 직업 수치는 `CLASSES`, 상점 가격과 등급 확률은 `SHOP`에서 조정합니다. 값을 바꾼 뒤 시뮬레이터로 직업별 층 돌파율을 확인할 수 있습니다.

```bash
node tools/simulate.js 300
```
